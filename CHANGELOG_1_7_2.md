# Khitun Geo 1.7.2

- Название проекта перенесено в левую панель, элементы преобразования выровнены; разделитель таблицы и графика расположен под центром кнопки ⇄.
- Первое знакомство: история приложения, понятия координат, импорт, пересчёт, экспорт, высоты и глубины. Повторное открытие из справки.
- Автоматическая проверка и загрузка релизов GitHub при запуске. Проверка SHA-256; установка поверх текущей версии по кнопке, после сохранения и отдельной резервной копии. Отмена загрузки и отключение автозагрузки для экономии трафика.
- Для перехода со старой версии без механизма обновления установите 1.7.2 вручную поверх неё. Последующие обновления доступны внутри приложения. Портативная копия требует ручной установки.
- Контроль качества, 2D DXF, профили настроек, паспорт преобразования HTML/PDF, сравнение съёмок по точным номерам и пакетный экспорт ZIP.
- Локальное чтение DWG через ACadSharp: 2D-подложка, вложенные блоки с базовой точкой/поворотом/масштабом, дуговые сегменты полилиний и слои с кириллицей. Слой 0 наследуется от вставки; выключенные и замороженные слои из файла скрыты по умолчанию. DWG до 16 МБ. Исходный файл не изменяется.
- Дуги хранятся аналитически, детализация отображения зависит от масштаба; невидимые за экраном объекты не рисуются. Крупные проекты в Windows сохраняются в отдельный атомарно заменяемый файл с предыдущей копией; старое браузерное хранилище переносится без удаления. В браузерном режиме остаётся его ограничение объёма.
- Ctrl/Shift выделяют отдельные столбцы и диапазоны; Delete очищает их значения во всех строках, Ctrl+Z восстанавливает данные.

## Ограничения

Пересчёт сохраняет введённую Z; преобразование систем высот и геоида не выполняется. DXF должен уже быть в нужной СК; поддерживается ограниченный набор 2D-объектов. Автоматическое обновление требует интернета и опубликованного стабильного установщика с SHA-256. Приложение не перезапускается во время работы без нажатия кнопки установки.

## Проверка перед публикацией

Этот файл пока описывает локальную подготовку версии. Выпуск остановлен по указанию пользователя. До публикации обязательны сборка Windows, тесты обновления, проверка установщика поверх существующей версии с сохранением данных и просмотр нового интерфейса. Ручные проверки PDF и реальных данных пока не завершены.
