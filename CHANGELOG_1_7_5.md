# Khitun Geo 1.7.5

- Оптимизирована работа с крупными DXF/DWG-подложками.
- Отрисовка ограничивает количество одновременно выводимых объектов и вершин, сохраняя исходную геометрию проекта.
- Расчёт границ чертежа больше не создаёт временный массив по всем объектам.
- Проверка данных чертежа не создаёт полную JSON-копию геометрии.
- Правка точек и обычные действия Undo/Redo не дублируют тяжёлый чертёж в истории. Полное состояние геометрии сохраняется для действий с самим чертежом и слоями.
