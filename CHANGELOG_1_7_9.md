# Khitun Geo 1.7.9

- Приложение запускается в нативном интерфейсе Windows Forms.
- Удалены Microsoft.Web.WebView2 и старое главное окно на основе WebView2.
- Удалены проекты и автосохранение; точки сохраняются по явной команде.
- Экспорт PDF и интерфейс обновления перенесены на нативные диалоги.
- В инструмент высоты добавлены задание значения всем точкам, общая поправка и расчёт «абсолютная отметка − глубина»; операция отменяется через Ctrl+Z.
- Добавлен экспорт AutoCAD `.scr` для создания всех точек в WCS командами `POINT`.
- Добавлен экспорт `.xlsx` без Microsoft Excel и дополнительных NuGet-пакетов; включены текущая СК и описание, пустая высота остаётся пустой.
- Проверка качества не выполняется при каждом ручном вводе. Перерисовка геометрии после правки объединяется 120-мс таймером; при скрытой визуализации он остановлен.
- Проверка сборки и ручной запуск на Windows ещё требуются.
- Добавлен Windows smoke-тест, создающий настоящий список систем координат из приложения.
- Формулы координат и расчётное ядро не менялись.

Установщик Windows x64. Сборка приложения и автоматические проверки выполняются в GitHub Actions.
