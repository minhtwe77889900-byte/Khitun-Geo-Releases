Khitun Geo 1.7.9 — краткая инструкция

Приложение запускает нативное окно Windows Forms. WebView2 Runtime не нужен.
Новые точки вводятся в таблице. Данные можно вставлять из Excel/CSV/текста,
импортировать из файлов и загружать из DWG/DXF. Экспорт включает AutoCAD `.scr`
и книгу Excel `.xlsx`; для XLSX Excel на компьютере не нужен. Перед преобразованием
проверьте выбранные исходную и целевую системы координат и зоны.

Преобразование пересчитывает X/Y и сохраняет исходное значение Z. Для явного
изменения высоты используйте «Высота ±». Ctrl+Z отменяет последнее действие.
Визуализация чертежа включается отдельно; кнопка «Слои» управляет видимостью.
В «Экспорт точек» доступен AutoCAD-скрипт `.scr`: сохраните его, затем в AutoCAD
выполните `SCRIPT` и выберите файл. Он создаёт все точки в мировой СК.

Для долговременного хранения точек используйте «Сохранить CSV» или экспорт.
Автоматического сохранения и проектов нет. При закрытии с несохранёнными
изменениями приложение предложит сохранить точки в CSV.

Установщик предназначен для Windows x64, сборка 19041 и новее; он не подписан.
Формулы и параметры систем координат проверяйте по официальным контрольным
точкам до применения результатов на объекте. Проверка Windows-сборки и
визуальная сверка DWG/DXF выполняются отдельно.
