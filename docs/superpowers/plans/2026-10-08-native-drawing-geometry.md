# Нативная геометрия DWG/DXF — план реализации

**Goal:** Отображать геометрию полилиний и вложенных блоков с управлением слоями, ограничивая подложку областью точек.

**Architecture:** Неизменяемый граф определений блоков и вставок хранит повторную геометрию один раз. Портативный обход применяет плоские преобразования, наследование слоёв и отсечение до передачи объектов WinForms-отрисовке. Существующий асинхронный импорт заменяет сцену только после успешного чтения.

**Tech Stack:** C# / .NET 8, WinForms, ACadSharp 3.7.16; без новых зависимостей.

**Spec:** `docs/superpowers/specs/2026-10-08-native-drawing-geometry-design.md` — согласована пользователем сообщением «Приступай» после предъявления документа.

## Review Focus

1. Повторные блоки с разными слоями: общий кэш не должен смешивать наследование слоя 0 между вставками — тест задачи 3.
2. Отражение и вложенные неравномерные масштабы: дуга сохраняет направление и форму эллипса — тесты задач 1 и 2.
3. Огромная вложенная кратность при малом числе определений: обход ограничен и сообщает о неполном отображении — тест задачи 3.
4. Линия пересекает область точек, обе вершины вне её: линия остаётся видимой — тест задачи 3.
5. Ошибка импорта при открытом окне слоёв или закрытии главного окна: сохраняются прежняя сцена и корректный жизненный цикл — проверки задачи 4.
