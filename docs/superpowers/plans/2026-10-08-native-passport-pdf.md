# План реализации паспорта преобразования и PDF

> **Для исполнителя:** использовать `superpowers:executing-plans`, выполнять задачи по порядку в текущей сессии. Пункты отмечаются `[ ]`. Реализация начинается после рассмотрения плана пользователем.

**Цель:** сохранять паспорт успешного нативного преобразования напрямую в PDF без WebView2.

**Архитектура:** модель паспорта хранит неизменяемые данные операции; существующий JS проверяет качество через отдельный ограниченный Jint. PDFsharp создаёт документ из снимка. Форма отвечает за состояние кнопки, диалоги, отмену и связь с историей изменений.

**Стек:** C#, .NET 8, WinForms, существующий Jint 4.16.2, PDFsharp Core 6.2.4.

**Дизайн:** `docs/superpowers/specs/2026-10-08-native-passport-pdf-design.md`.

## Общие ограничения

- Офлайн-работа на Windows x64. Формулы, параметры СК и существующие JS-модули не изменять.
- Сохранять основной экран и переключатель `--native-preview`; WebView2 пока не удалять.
- Не загружать на GitHub, не создавать установщик, не публиковать и не коммитить без отдельной команды пользователя.
- Не вводить проекты, автосохранение, экспорт HTML или выдуманные сведения о точности.
- PDF: A4, книжная ориентация, поля 15 мм, основной текст 10–11 пунктов, русский язык.
- Не более 500 замечаний в документе; полный счётчик обязателен.
- Хеширование: SHA-256, UTF-8, формат `native-v1`, без округления координат.
- Обновлять паспорт только при успешном применении результата; отмена возвращает предыдущий паспорт и настройки.
- Существующий файл сохраняется при ошибке или отмене экспорта.
- Реальные пакеты и шрифты обязательны. Прямая компиляция не подтверждает работу интерфейса Windows.

## Особое внимание при проверке

- Преобразование, не изменяющее координаты: новый паспорт должен иметь отмену, даже если обычный ReplacePoints пропускает одинаковые данные — тест задачи 4.
- Изменение таблицы, повторный расчёт и несколько отмен: паспорт и настройки должны соответствовать истории — тест задачи 4.
- Длинные названия и непрерывный текст: PDF не обрезает строки и не накладывает их друг на друга — проверка задачи 3.
- Ошибка шрифта, занятой файл и отмена перед заменой: предыдущий файл остаётся целым, временный удаляется — тест задачи 3.
- Отсутствующие высоты и больше 500 замечаний: предупреждения не пропадают и не превращаются в сообщение об успешной проверке — тест задачи 2.
