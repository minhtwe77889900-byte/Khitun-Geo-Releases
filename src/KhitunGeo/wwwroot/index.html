Знакомство с Khitun Geo

Главная цель

Помочь работать с координатами в условиях Крайнего Севера. Интернет есть не всегда, а точки нужно перевести в другую систему координат. Khitun Geo позволяет сделать это без подключения к сети.

История создания

Всё началось с таблицы Excel для пересчёта координат и подготовки точек для Civil 3D. Затем появилась идея отдельного приложения — чтобы загружать точки, пересчитывать их, смотреть на графике и сохранять результат в одном месте.

Так появился Khitun Geo. Приложение развивается на основе реальных рабочих задач и замечаний, которые возникают при его использовании.

Что такое точки и координаты?

Точка — место, которое измерили: например, угол здания или отметка дна. Одна строка таблицы — одна точка. Номер помогает её найти, описание объясняет, что измерено.

Координаты задают положение. В плоских системах Khitun Geo использует X — север и Y — восток, обычно в метрах. В географических системах B — широта и L — долгота в градусах. Z / H — введённая высота.

Система координат (СК) — правила, по которым записано положение. Одинаковые числа в разных СК могут означать разные места. Узнайте исходную СК, зону и единицы у того, кто передал файл; программа не может надёжно угадать их по числам.

Зона — часть территории, для которой настроена проекция. При обмене с AutoCAD порядок осей может отличаться: проверьте соответствие столбцов в предпросмотре импорта.

Первый результат — за пять шагов

  1. Откройте проект через значок проекта слева или начните новый. Сохраните исходный файл отдельно.
  2. Загрузите точки: перетащите CSV, TXT, XYZ, JSON или GeoJSON в приложение. Если появится мастер, сопоставьте номер, X/B, Y/L, Z и описание. Проверьте несколько строк перед импортом.
  3. Укажите СК: сверху слева — система координат загруженных точек, справа — нужная система результата. Через «Зона» проверьте её настройки. Кнопка ⇄ только меняет настройки местами, точки она не пересчитывает.
  4. Нажмите «Преобразовать». Результат появится в таблице. Через «Анализ → Контроль качества» проверьте ошибки данных и сравните результат с известной контрольной точкой. Ctrl+Z отменяет действие.
  5. Сохраните: «Данные → Экспортировать точки» — файл для другой программы; меню проекта → «Сохранить проект JSON» — точки вместе с настройками для продолжения работы.

Для Civil 3D в разделе «Данные» есть подготовка экспорта PNEZD: номер, север, восток, высота, описание. Получателю также передайте название СК и сведения о высотах.

Высота, глубина и безопасное редактирование

Высота и глубина — разные величины. Для глубины выберите её в списке над графиком и задайте уровень отсчёта в той же системе высот. Например: уровень 100 м, Z = 97 м — глубина 3 м. При уровне 0 м и Z = −12,4 м глубина равна 12,4 м.

Пересчёт координат сохраняет введённую Z. Перевод между системами высот и поправка геоида не выполняются. Пустая высота не означает ноль.

Таблица: щёлкните по значению для редактирования. Ctrl + клик по заголовкам выбирает отдельные столбцы, Shift — диапазон. Delete очищает выбранные столбцы во всех строках; сами столбцы остаются. При выделенных строках Delete удаляет строки. Ctrl+Z возвращает данные, Ctrl+Y повторяет действие.

График: колесо мыши меняет масштаб, средняя кнопка перемещает вид, «Вписать все» возвращает точки в окно. «＋ Точка» позволяет задать положение мышью и уточнить координаты перед добавлением. Такой щелчок не заменяет измерение на местности.

Куда идти дальше

Проект — открытие, сохранение, резервные копии и профили настроек.
Данные — импорт, экспорт, пакетное преобразование и паспорт результата.
Анализ — проверка данных и сравнение съёмок по номерам точек.
Вид — 2D-чертёж DXF или DWG поверх точек. Его СК и единицы нужно подтвердить; чертёж не перепроецируется автоматически. DWG открывается в приложении Windows без AutoCAD и интернета; блоки и поверхности Civil 3D не отображаются.

Контроль качества находит ошибки записей, но не подтверждает точность измерений. Для рабочих расчётов нужны достоверные исходные данные и проверка результата.

Это руководство всегда доступно в «Справке». Тему можно переключить кнопкой внизу левой панели.

При запуске приложение может проверить и загрузить новую версию. После загрузки появится кнопка «Обновление готово»: установка начнётся после сохранения проекта и резервной копии, затем программа перезапустится. Автозагрузку можно отключить в настройках для экономии трафика. Проверка вручную доступна в справке.

Обновления приложения

Новые версии устанавливаются поверх текущей. Проекты и настройки сохраняются.

Выбранные системы координат

Ctrl+Z — отмена добавления, удаления, редактирования и пересчёта точек, импорта и изменения настройки зоны. Хранятся последние 30 действий текущего проекта.

В текстовых полях вне таблицы Ctrl+Z отменяет ввод текста. Проекты открываются с новой историей действий.

Визуализация: удерживайте среднюю кнопку мыши для перемещения, вращайте колесо для масштаба. Левая кнопка выбирает точку. Кнопка «＋ Точка» включает создание точки щелчком; координаты и Z подтверждаются в окне.

Строки выбираются по номеру: протягивание мышью, Shift — диапазон, Ctrl — добавление. Столбцы выбираются по заголовку такими же способами. Ctrl+Y — повтор действия. Файл можно перетащить в программу; неясный формат требует подтверждения в мастере.

В списке подписей можно выбрать высоту Z или глубину. Глубина = уровень отсчёта − Z; обе величины задаются в метрах в одной системе высот. Без уровня или Z отображается прочерк. Отрицательная глубина означает, что точка выше уровня.

Уровень сохраняется в проекте. Пересчёт меняет X/Y, но сохраняет введённую высоту Z и уровень отсчёта. Преобразование вертикальных датумов и геоида не выполняется. Показ глубины не меняет исходные точки и экспорт.

Настройка зоны

Автоматически: зона результата определяется по долготе, исходной ГК — по префиксу Y. Для исходной UTM номер зоны укажите вручную даже при автоматическом режиме. Для МСК и СК-63 регион и зона выбираются в списках систем.
