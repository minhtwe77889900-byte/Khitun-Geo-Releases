# Повторяемый замер геометрии

Запуск из корня проекта:

```bash
bash tests/NativeDrawing/verify-direct.sh /workspace/scratch/3d9e1b00c9bd/tooling/dotnet /workspace/scratch/3d9e1b00c9bd/tooling/dwg-test/ACadSharp.dll --benchmark
```

Также доступен `dotnet run --project tests/NativeDrawing -- --benchmark` в окружении с работающим SDK.
Обычные регрессионные проверки выполняются до замера.

Образец: DWG 2018 и DXF из одного CadDocument, 2020 вставок общего
вложенного блока (20 рядом с точками, 2000 далеко). Основное определение
содержит 100 линий и окружность; промежуточный блок — одну вставку.
В результирующей сцене 3 определения и 2122 сохранённых элемента,
вместо 204020 отдельных примитивов при полном разворачивании.
Область точек: (-5,-5)→(105,105). Есть один прогрев чтения и три измерения.

Локальный запуск 2026-10-08: Linux, .NET runtime 8.0.20, SDK compiler
8.0.414, ACadSharp 3.7.16; синтетические данные, не пользовательский чертёж.
Выделения — `GC.GetTotalAllocatedBytes(true)` за чтение/построение,
включая временные объекты; это не остаточная память и не working set.
Сам fixture/writer не входят в замер. На shared host время изменчиво.

| Формат | Размер файла | Чтение + построение, мс | Управляемые выделения | Обход без области, мс | Обход области точек, мс |
|---|---:|---:|---:|---:|---:|
| DWG | 45 217 байт | 34,11–46,45 | около 15,93 МБ | 123,42–128,90 | 2,50–2,86 |
| DXF | 475 070 байт | 103,74–116,99 | 26,43–26,48 МБ | 118,26–159,30 | 2,60–6,69 |

Без области: 200000 посещений, 196116 выданных примитивов и явный
`Truncated=true`; это ограниченный, а не полный обход всех вставок.
С областью точек: 4060 посещений, 2020 примитивов, `Truncated=false`.
Эти точные количества проверяются assertions во всех прогонах.
Далёкие вставки проверяют свою границу, но их общая дочерняя геометрия
не обходится. Определения остаются общими для близких и далёких вставок.

Замер доказывает работу отсечения и общего хранения на этом образце.
Он не сравнивает прежний WebView2 с новым UI, не измеряет GDI/частоту
кадров, не доказывает снижение RAM всего приложения и не устраняет
чтение всего документа ACadSharp. Окончательные нагрузочные проверки,
paint time, idle/loaded working set и отзывчивость выполняются на Windows
на одинаковых реальных чертежах по `tests/NativeWorkspace/WINDOWS_SMOKE.md`.
